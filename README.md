# Preparation Pilot 🎯

An AI-powered interview preparation platform designed to help software engineers systematically prepare for confirmed interviews.

Instead of generic question banks or ungrounded AI chat prompts, **Preparation Pilot** parses the actual Job Description (JD), cross-references role requirements against your personal skills profile (backed by real production evidence), identifies actionable skill gaps, and generates targeted practice questions with an auditable readiness score.

---

## 🚀 Key Features

* **Confirmed Interview Management**: Track scheduled interviews by company, role title, round format (*System Design*, *Technical Screening*, *Behavioral*, etc.), and status.
* **Evidence-First Skills Profile**: Document skills with practical evidence (e.g. production architecture vs. tutorial knowledge) rather than arbitrary proficiency labels.
* **Evidence-Backed Skill-Gap Detection**: AI identifies requirements directly from the JD text, compares against your logged evidence, cites JD excerpts, and allows candidate corrections/overrides.
* **Targeted Practice Question Generation**: Produces 5–10 high-yield questions addressing detected gaps and specific round formats, complete with sample talking points.
* **Deterministic Readiness Tracking**: Backend-calculated progress metric based on answered questions and completed preparation checklist items (not generated by AI).

## 🏗️ Architecture & Technology Stack

```
+-----------------------------------------------------------+
|                    Angular Frontend                       |
|  - Standalone Components & Signal-based state             |
|  - Modern, responsive dashboard & prep room               |
+-----------------------------+-----------------------------+
                              | REST / JSON
+-----------------------------v-----------------------------+
|                     NestJS Backend                        |
|  - Modular architecture (Profile, Interview, AI, Prep)    |
|  - Prisma ORM with PostgreSQL                             |
|  - Google Gemini API integration (Structured JSON output) |
+-----------------------------+-----------------------------+
                              |
+-----------------------------v-----------------------------+
|                  PostgreSQL (Dockerized)                  |
|  - Relational persistence for profiles, gaps & questions  |
+-----------------------------------------------------------+
```

### Tech Stack
* **Frontend**: [Angular](https://angular.dev/) (v18+, Standalone Components, Signals)
* **Backend**: [NestJS](https://nestjs.com/) (TypeScript)
* **Database**: [PostgreSQL](https://www.postgresql.org/) managed via [Prisma ORM](https://www.prisma.io/)
* **AI Engine**: Google Gemini API with structured JSON output schema validation
* **Containerization**: Docker & Docker Compose

## 🛠️ Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (v20+ recommended)
* [Docker Desktop](https://www.docker.com/) (for PostgreSQL)
* [Git](https://git-scm.com/)

### 1. Start the Database
```bash
docker compose up -d
```

### 2. Backend Setup
```bash
cd backend
npm install
npx prisma migrate dev
npm run start:dev
```

### 3. Frontend Setup
```bash
cd frontend
npm install
npm start
```
